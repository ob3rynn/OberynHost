# Support Scope

OberynHost sells self-managed Minecraft hosting capacity, panel access, and the platform services needed to run the purchased server.

OberynHost support covers:

- billing and subscription questions tied to an OberynHost purchase,
- Stripe Billing Portal access when the verified purchase has billing context,
- panel account access and ready-access email delivery,
- purchased service unavailable because of platform, node, routing, or allocation issues,
- provisioning or setup failure,
- hostname or routing issues caused by OberynHost,
- node or network availability problems,
- incorrect plan allocation,
- a clean baseline Paper server failing because of an OberynHost template, runtime, or platform configuration,
- OberynHost-required plugin or configuration issues.

Support is intended for the Minecraft server owner/operator who purchased the service.
