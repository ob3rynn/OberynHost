# No-Login Service Access

OberynHost customers do not have customer accounts in the storefront.

Customer service access is handled through private service access links sent in OberynHost-controlled billing and service emails. The latest OberynHost email for a server should contain the current private service access link for that server.

Private service access links:

- open support, billing help, service status, and ready-access options for one purchased service,
- are bearer credentials, so anyone with the link may be able to access support options for that service,
- refresh each Stripe billing cycle,
- keep the previous billing-cycle link valid only for a short overlap window,
- expire instead of living forever,
- can be rotated or revoked by an admin.

Customers should save the latest OberynHost service email or bookmark the private service access link. If an older link stops working, they should use the newest OberynHost billing/service email.

If a customer cannot access their private service access link, they can email support@oberynn.com for purchase-access recovery. Email alone must not create verified support context or open a support ticket.
